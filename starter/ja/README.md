# 卒業論文・修士論文テンプレート（日本語・起稿用）

法政大学 知能システム研究室

章立てと必要なコメントだけを残した起稿用です．図表・コードの組版例は別配布の例付き版を参照してください．

## 使い始める

1. 知能システム研究室の学生は，指導教員が用意した Overleaf のプロジェクトを使います．
   それ以外の場合は，このフォルダ全体をコピーするか，起稿用 zip を Overleaf にアップロードします（無料プランではコンパイルがタイムアウトすることがあります）．
2. コンパイラに **LuaLaTeX** を指定します．ローカルではこのフォルダで `latexmk main.tex` を実行します．
3. `main.tex` の題目・氏名・フリガナ・学生証番号・指導教員を変更します．修士の場合は `bachelor` を `master` に変更します．
4. `\fiscalyear{2026}` を自分の提出年度（4月〜翌年3月）に変更し，定稿後は固定します．
5. `chapters/` のコメントを参考に本文を書きます．章名や節名は研究に合わせて変更できます．

初期状態の PDF に本文がなく，章・節見出しのみが表示されるのは正常です．
`hosei-thesis.cls` と `latexmkrc` は編集・削除しないでください．

## 参考文献・図・任意の項目

- `references.bib` は空です．実際に読んだ文献を登録し，著者名は原典の順序で全員を保存します．
- 本文に `\cite{キー}` を書いた後，`main.tex` の `\bibliography{references}` の行頭の `%` を外します．引用のない初期状態ではコメントのままにします．
- 図は `figures/` に置きます．図表・式・章の参照には `\label{…}` と `\cref{…}` を使います．
- 図目次・表目次・研究業績・付録は，必要になった時に `main.tex` の該当行を有効にします．付録は `\appendix` の行も必要です．
- 添削時にはクラスオプションに `review` を追加します．行番号・添削用の日付・`\TODO{…}`・`\rev{…}` の色付けが表示されます．

## 提出前

- [ ] 本文を書き終え，空の章・節や不要な項目を削除した
- [ ] 表紙の情報と `\fiscalyear{…}` の提出年度を確認した
- [ ] `review` を外し，`\TODO` を残していない
- [ ] 図表は自分の研究の結果であり，すべて本文で参照・説明した
- [ ] 調整用と最終評価用のデータを分け，比較条件・種・実行回数・停止条件を明記した
- [ ] 平均や標準偏差が問題例間と種の間のどちらのばらつきを示すか説明した
- [ ] 文献の書誌情報を原典と照合し，未定義の引用・参照や警告がない
- [ ] 提出方法，ファイル名，容量などを当該年度の指示で確認した
