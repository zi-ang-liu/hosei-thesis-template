# 卒業論文テンプレート（日本語版）

法政大学 理工学部 経営システム工学科　知能システム研究室

## まず読むこと

- コンパイルには **LuaLaTeX** を使います．
- 編集するのは次のファイルだけです．`hosei-thesis.cls` と `latexmkrc` は**編集・削除しないでください**．

| ファイル | 内容 |
|---|---|
| `main.tex` | 論文情報（題目・氏名・学生証番号など）と章の並び |
| `chapters/` | 各章の本文（1 章 = 1 ファイル） |
| `references.bib` | 参考文献のデータ |
| `figures/` | 図のファイル（PDF・PNG・JPEG） |

各章のファイルには，その章に書く内容と LaTeX の書き方がコメント（`%%` の行）で説明してあります．

修士論文の場合は，`main.tex` のクラスオプションの `bachelor` を `master` に変更します（`\documentclass[ja,master]{hosei-thesis}`）．
表紙の論文種別と所属が修士論文用になり，フリガナ（`\authorkana`）が必須になります．

このフォルダは**例付き版**です．PDF の「執筆ガイド（提出時に削除）」は書き方の説明であり，論文本文ではありません．
`writingnote` 環境は提出前に環境ごと削除し，本文の例は自分の研究に置き換えてください．
実験の図表は架空データであり，実測値として使用できません．
章立てと必要なコメントだけで書き始めたい場合は，別配布の **`hosei-thesis-ja-starter.zip`**（リポジトリ内の `starter/ja/`）を使ってください．

## 章の構成

| ファイル | 章 | 書くこと |
|---|---|---|
| `01-introduction.tex` | はじめに | 背景，課題，目的，貢献，論文の構成 |
| `02-preliminaries.tex` | 準備 | 対象とする問題の定義や，用いる手法の基礎（**既存の知識**） |
| `03-related-work.tex` | 関連研究 | 関連する研究の整理と，本研究の位置づけ（提案手法の直前に，既存研究の課題を示す） |
| `04-method.tex` | 提案手法 | **自分が考えた部分**．第三者が再現できる程度に具体的に |
| `05-experiments.tex` | 数値実験 | 実験設定（問題・比較手法・評価指標・パラメータ・環境），結果，考察 |
| `06-conclusion.tex` | 結論 | まとめと今後の課題 |
| `publications.tex` | 研究業績 | 在学中の論文・学会発表の一覧（業績がない場合は `main.tex` の該当行を削除） |

「準備」（教科書や論文に書いてあること）と「提案手法」（自分の提案）は，章を分けてはっきり区別します．
章の数や名前は研究に合わせて変えてかまいません．

## Overleaf で使う

1. 知能システム研究室の学生は，指導教員が用意したプロジェクトに招待されます．招待メールのリンクから開き，そのまま使ってください．
   自分のアカウントに Copy すると，Overleaf の無料プランではコンパイルがタイムアウトすることがあります（上限 10 秒）．
2. それ以外の場合は，GitHub の [Releases](https://github.com/zi-ang-liu/hosei-thesis-template/releases/latest) から zip をダウンロードし，
   Overleaf の New Project → Upload Project でアップロードして，Menu → Settings → Compiler を **LuaLaTeX** にします．
   無料プランでタイムアウトする場合は，自分の PC でコンパイルしてください（下記）．
3. 最初のコンパイルは，フォントの準備のため時間がかかることがあります．

## 自分の PC で使う

- TeX Live 2023 以降をインストールします．
- このフォルダで `latexmk main.tex` を実行すると `main.pdf` ができます（`latexmkrc` の設定で LuaLaTeX と upBibTeX が使われます）．
- VS Code（LaTeX Workshop）では，レシピ **「latexmk (latexmkrc)」** を選びます．

## 指導教員に見せるとき（添削モード）

`main.tex` のクラスオプションに `review` を加えます．

```latex
\documentclass[ja,bachelor,review]{hosei-thesis}
```

- 左に行番号が付きます（「12 行目の……」とコメントしやすくなります）．
- `\TODO{あとで書く}` が赤字で表示されます．
- `\rev{修正した文}` が青字になります（前回からの修正箇所を示すときに使います）．
- 各ページの右上に「添削用」と日付が入ります．

提出する最終版では `review` を外します．`\TODO` は表示されなくなり，残っていると警告が出ます．`\rev` は普通の文字になります．

## よく使う書き方

| やりたいこと | 書き方 |
|---|---|
| 章・節 | `\chapter{…}`，`\section{…}`，`\subsection{…}` |
| 図・表・式などの参照 | `\label{fig:result}` を付け，本文で `\cref{fig:result}` →「図4.1」 |
| 文献の引用 | `\cite{dantzig1957discrete}` →「[1]」のような番号．複数なら `\cite{a,b}` |
| 図 | `\includegraphics[width=0.8\linewidth]{ファイル名}`（`figures/` に置く） |
| 図を並べる | `subfigure` 環境（`chapters/05-experiments.tex` に例） |
| 簡単な図を描く | `tikzpicture` 環境（TikZ．`chapters/04-method.tex` に例） |
| 表 | `table` 環境と `tabular`（`chapters/03-related-work.tex`，`05-experiments.tex` に例） |
| 数式 | 文中は `$…$`，独立した式は `equation`，複数行は `align`（`chapters/02-preliminaries.tex` に最適化問題の例） |
| 項目や記号の定義を並べる | `description` 環境（`chapters/04-method.tex` に例．記号の一覧の例は `02-preliminaries.tex` のコメント） |
| 箇条書き | `itemize`（記号），`enumerate`（番号） |
| アルゴリズム | `algorithm` 環境（`chapters/02-preliminaries.tex` に例） |
| ソースコード | `lstlisting` 環境（`chapters/appendix.tex` に例） |

各章の例（0-1 ナップサック問題など）は書き方を示すためのものです．自分の研究の内容に置き換えてください．

- 「図」「表」「第3章」などの語と番号は `\cref` が自動で付けます．番号を手で書かないでください．
- ラベル名は `chap:` `sec:` `fig:` `tab:` `eq:` `alg:` `lst:` で始めると分かりやすくなります．
- アルゴリズムは algorithm2e パッケージ（読み込み済み）で書きます．`algorithm`・`algorithmic`・`algpseudocode` パッケージとは併用できないので，`\usepackage` で追加しないでください．
  ほかの資料の擬似コードを使うときは，algorithm2e の書き方に直します．

## 参考文献（references.bib）

`references.bib` には，書籍・論文誌・国際会議・Web ページなど，形式ごとの例が入っています．
論文の書き方の参考書（木下『理科系の作文技術』，酒井『これから論文を書く若者のために』）も含めてあるので，一度読んでおくとよいでしょう．

**文献の探し方と BibTeX の入手**

- 英語の文献：Google Scholar（引用 → BibTeX），DBLP（情報系の会議・論文誌），出版社のページ．
- 日本語の文献：CiNii Research，J-STAGE（論文のページから BibTeX をダウンロードできる）．
- 自動で作られた BibTeX には誤りや抜けが多いので，著者名・題目・巻・号・ページ・年を必ず原典で確認してください．
- 文献が多い場合は Zotero などの文献管理ソフトで管理し，BibTeX を書き出すと便利です（任意）．

**書き方**

- キーは `dantzig1957discrete` のように「第一著者の姓 + 年 + 題目の最初の単語」を半角英数字で付けます．
- 日本語の文献も英語と同じ形式で書けます．著者は「姓 名」を `and` で区切ります．
- 著者は原典の順序で全員を記録し，`and others` で手動省略しません．表示時の省略は参考文献スタイルに任せます．
- Web ページは misc 形式で，URL と参照日を書きます（`references.bib` の例を参照）．
- `.bib` ファイルでは，`%` の後ろでもアットマーク記号を書かないでください（コメントにならず，エラーになります）．
- 本文で `\cite` した文献だけが，引用した順に番号が付いてリストに載ります．

**何を引用するか**

- 査読のある論文誌・国際会議の論文や，書籍などの原典を引用します．孫引き（他の文献に書かれている内容を，原典を読まずに引用すること）はしません．
- Wikipedia，個人のブログ，生成 AI の出力は引用しません．Web ページは公式の情報（ソフトウェアのドキュメント，公的統計など）に限ります．

## 注意

- 段落は空行で区切ります．`\\` で改行しないでください．
- 句読点は「，」「．」に統一します．
- 図はできるだけ PDF（ベクター形式）で作ります．draw.io や PowerPoint で作った図は PDF で保存し，matplotlib のグラフは `plt.savefig("figure.pdf")` で保存します．写真は PNG や JPEG を使います．
- エラーが出たら，ログの**最初の**エラーから読みます．`!` で始まる行とその行番号を確認してください．
- 図目次・表目次が必要なら，`main.tex` の `\listoffigures` と `\listoftables` の行頭の `%` を外します．
- 日本語の題目は単語の途中でも改行されるので，`\titleJA{前半\\後半}` のように `\\` で表紙の改行位置を指定します．
- `main.tex` の `\fiscalyear{2026}` を提出年度（4 月〜翌年 3 月）に変更し，定稿時には固定してください．この指定を省くとコンパイル日から自動計算されるため，後年の再コンパイルで年度が変わります．
- 記号は分野の標準的な教科書の書き方に合わせます（例：強化学習なら Sutton と Barto の教科書）．ベクトルは太字，集合は花文字など，論文全体で統一します．

## 提出前のチェックリスト

- [ ] `review` オプションを外した（行番号や「添削用」が出ていない）
- [ ] `\TODO` が残っていない（ログに「TODO remains」の警告が出ていない）
- [ ] ログに警告（Warning）が出ていない．特に「undefined」（未定義の参照・引用）がない
- [ ] 表紙の題目・氏名・フリガナ・学生証番号・指導教員が正しい
- [ ] `\fiscalyear{…}` に正しい提出年度を明記し，表紙でも確認した
- [ ] すべての図・表が本文で参照され，説明されている
- [ ] 参考文献の著者・題目・巻・号・ページ・年を確認した
- [ ] 「……」や「○○」などの例の文が残っていない
- [ ] `writingnote` 環境を削除し，架空の図表・比較表を実際の研究内容に置き換えた
- [ ] 提出方法とファイル名が指示どおりである
